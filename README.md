# AttendX Test Scripts

## Project Description
This repository contains sample automation test scripts
for the AttendX student attendance application.

## Test Scripts

1. login_test.py
   - Checks login input validation.

2. attendance_test.py
   - Checks student ID and attendance status validation.

## Technologies Used
- Python
- Git
- GitHub
- Visual Studio Code

## Purpose
To maintain test scripts using version control,
track changes, and collaborate with QA team members.

Maintained by the AttendX QA team.
